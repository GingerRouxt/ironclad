# Roadmap

The current beta includes local diagnostics, optional detection components, reviewed actions and AI explanations. Priorities are clean-machine install/update/removal and reboot testing, broader accessibility and performance checks, independent security review, complete dependency/SBOM review, and better measured detection coverage.

Marketplace publication and maintainer verification completed October 25, 2026 for `73e2275`. A listing does not certify security or cover later changes automatically. Community Ironclad remains free. ZDS Core is a separate product direction; the [optional fleet interface](CORE_INTERFACE_PROPOSAL.md) is design only, not an implemented connector.
