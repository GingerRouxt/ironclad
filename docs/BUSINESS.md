# Zero Day Security

Ironclad is a Zero Day Security project for Omarchy, published under the repository's MIT license. It has no telemetry, sales enrollment, endpoint identifiers or automatic report transfer to a business service.

[Zero Day Security](https://szdsecurity.com/) also develops ZDS Core. Ironclad has no runtime dependency on Core and does not claim an implemented fleet-management connector. Any future integration needs a separately defined scope and explicit user consent. No permanent pricing commitment or Omarchy endorsement is implied.
