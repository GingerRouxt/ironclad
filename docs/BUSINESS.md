# Zero Day Security

Ironclad is a Zero Day Security project for Omarchy, published under the repository's MIT license. It has no telemetry, sales enrollment, endpoint identifiers or automatic report transfer to a business service.

Community Ironclad remains free and MIT licensed. [Zero Day Security](https://szdsecurity.com/) also develops ZDS Core as a separate product direction. Ironclad has no runtime dependency on Core and no implemented fleet-management connector. Any future integration needs a separately defined scope and explicit user consent; see the [interface proposal](CORE_INTERFACE_PROPOSAL.md). No Omarchy endorsement is implied. Optional AI provider charges are separate from Ironclad.

The [landing-page brief](LANDING_PAGE_BRIEF.md) is a draft for review, not a deployed page or an instruction to modify production.
