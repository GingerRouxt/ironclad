# Launch announcement draft — not posted

**Ironclad 0.2.37 is available for Omarchy.**

Community Ironclad is a free, MIT-licensed desktop security companion from Zero Day Security. Review local system findings, understand the evidence, and choose what happens next. It brings Quick 90, Full 180 and Super Scan 420 diagnostics, optional Falco behavior monitoring, optional ClamAV scanning, software checks and AI explanations into the Omarchy desktop.

The Omarchy marketplace published and maintainer-verified snapshot `73e2275` on October 25, 2026. That is a scoped review of an exact snapshot—not independent security certification, an endorsement or a guarantee that your machine is malware-free. Automated, existing-desktop and headless VM checks passed; complete clean-desktop lifecycle and independent review remain separate work.

Install and review the requirements: [marketplace](https://omarchyplugins.com/plugin.html?id=com.zerodaysecurity.ironclad) · [source and installation](https://github.com/GingerRouxt/ironclad#get-ironclad).

Optional privileged engines and scheduled maintenance require separate setup. Version 0.2.37 keeps scans local until an explicit **Explain all checks** or another AI action. Signed Falco host-rule updates require their own opt-in and OS authentication. External provider terms and costs apply. There is no Core enrollment or report telemetry.

Contribute reproducible bug reports, accessibility feedback and synthetic test cases. Built for Omarchy, with credit to Falco, KRSI and ClamAV.
