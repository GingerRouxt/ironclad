# Launch announcement draft — not posted

**Ironclad is available for Omarchy.**

Community Ironclad is a free, MIT-licensed desktop security companion from Zero Day Security. Review local system findings, understand the evidence, and choose what happens next. It brings Quick 90, Full 180 and Super Scan 420 diagnostics, optional Falco behavior monitoring, optional ClamAV scanning, software checks and AI explanations into the Omarchy desktop.

The Omarchy marketplace published and maintainer-verified snapshot `73e2275` on October 25, 2026. That is a scoped review of an exact snapshot—not independent security certification, an endorsement or a guarantee that your machine is malware-free. This is a beta, with fresh-machine/reboot and exact-binary native acceptance still to complete.

Install and review the requirements: [marketplace](https://omarchyplugins.com/plugin.html?id=com.zerodaysecurity.ironclad) · [source and installation](https://github.com/GingerRouxt/ironclad#get-ironclad).

Optional privileged engines and scheduled maintenance require separate setup. Published 0.2.36 automatically asks an available signed-in AI client for explanations after GUI scans; use CLI diagnostics to avoid that transport. A post-launch PR changes this to an explicit **Explain all checks** action. External provider terms and costs apply. There is no Core enrollment or report telemetry.

Contribute reproducible bug reports, accessibility feedback and synthetic test cases. Built for Omarchy, with credit to Falco, KRSI and ClamAV.
