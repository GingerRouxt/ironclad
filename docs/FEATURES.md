# Features and limits

- Quick 90, Full 180 and Super Scan 420 distinct diagnostic predicates; [complete catalog](CHECK_CATALOG.md).
- Per-check evidence, Ignore/Restore and AI explanations for every selected check.
- Fresh scan display with private gzip archives of prior snapshots and completed answers.
- Supported software inventory, advisory checks and separately reviewed update actions.
- Eight selected Falco behavior categories, including scoped KRSI asynchronous write-open coverage.
- Optional automatic Downloads ClamAV scanning, separate one-off sandboxed file scans and signature maintenance.
- Local activity and HTML, JSON and Markdown reports.

Counts are catalog entries, not attack-detection scores. Unsupported or unavailable checks are not passes. Automatic alert-only scanning does not block or delete files. Prevention is a separate mode with incomplete native acceptance. A clean scan cannot establish that a machine is malware-free. See [coverage](DETECTION_COVERAGE.md), [privacy](PRIVACY.md) and [test results](../TEST_RESULTS.md).
