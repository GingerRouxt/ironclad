# Security policy

## Release status

This public repository currently contains presentation assets and documentation. There is no published plugin release or supported-version matrix here yet.

## Reporting a vulnerability

Use this repository's **Security → Advisories → Report a vulnerability** option if GitHub displays it. If private reporting is unavailable, open a minimal issue asking the maintainer for a private reporting channel. Do not include exploit instructions, credentials, private files, or sensitive logs in that public request.

Describe the affected component and version, expected behavior, impact, and a minimal reproduction using synthetic data in the private report. No response-time or bounty commitment is currently offered.

## Scope and expectations

Ironclad's checks and optional engines have bounded coverage. A clean result is not proof of a clean machine. AI guidance requires human review. Detection, maintenance, or compatibility failures should be surfaced as missing coverage rather than a healthy state.
